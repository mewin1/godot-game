# Застава — инструкции

Общаемся по-русски, кратко и понятно. Один разработчик-новичок.
Godot 4.7.x, GDScript, GUT 9.7.1. Соревновательный TD в славянском сеттинге.

## Работа без лишнего контекста
- На старте: `git status --short` и `memory/CURRENT.md` (держать до 40 строк).
- Перед кодом: блок «Всегда» DEVELOPMENT.md; остальные разделы только по задаче.
  Уже прочитанное в этом контексте повторно не читать без изменений.
- Реализацию искать через нужные строки memory/PROJECT_MAP.md, затем `rg` и
  ограниченные диапазоны файлов. Не выводить целиком каталоги, логи, конфиги.
- Правила: нужный раздел docs/CURRENT_RULES.md; числа — активные .tres из game_config.
  Новая концепция: docs/00_pitch.md и тематические решения/отказы из decisions.md.
  Для уже согласованной задачи достаточно её спецификации, без повторного аудита.
- Визуал: актуальная часть docs/06_visual_style.md; управление — docs/14_ui_fix_notes.md.
  Прочее искать через docs/README.md. Историю читать только по необходимости.
- Сначала короткий план; небольшие законченные изменения. Тесты/команды — с кратким
  итогом; подробный вывод читать только при ошибке. Не повторять успешные проверки
  без новых изменений. Не создавать большие отчёты без запроса.
- CURRENT — только точка продолжения; история — memory/sessions/. Обновлять только
  затронутые документы. Предложение, реализация и проверка автором — разные статусы.

## Не нарушать
- sim/ без нод: целые числа, фиксированный тик, свой RNG с сидом, ввод командами.
  Правила не в UI, числа в ресурсах. Типизировать GDScript полностью.
- Чужие незакоммиченные изменения сохранять. Без переделок вне задачи.
- Баг сначала воспроизвести тестом; sim проверять GUT/детерминизмом, визуал запуском.
  Баланс — живой игрой и логами; боты лишь ориентир. Указывать невыполненные проверки.
- Матч: один экран без прокрутки; лавка/армия слева, карта справа, идолы под ней.
  ПКМ поворачивает, сброс на лавку продаёт, заговор на цель, подарок сразу в слияние.
  PvP: резерв снизу, путь/место растут от магазина; теснота и резерв намеренны.
  Основной режим «Обряд» (docs/34): резерва нет — покупка сразу на клетку; лавка —
  мало случайных карточек и платное «Обновить»; чар на постройки нет.
- Три пустых идола развиваются заговорами без слияния копий. Попутный ветер ускоряет.
  Обычные армии — люди, сказочные существа — герои/персонажи.
- Только проект и Godot. Внешние конфиги/сеть/пакеты/домашний каталог — по согласованию.
  Коммиты без соавторства ИИ; логи и .godot/ в Git не добавлять.

## Проверки
Перед Godot: `XDG_CONFIG_HOME="$PWD/.godot/local-config" XDG_DATA_HOME="$PWD/.godot/local-data"`.
Игра: `godot --path .`. GUT: `godot --headless --path . -s res://addons/gut/gut_cmdln.gd -gexit`.
Полная проверка: `python3 -I tools/check_project.py`. Остальные команды — PROJECT_MAP.

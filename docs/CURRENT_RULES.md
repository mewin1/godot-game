# Действующие правила прототипа

Срез: 2026-10-31. Только реализованное; планы — `memory/CURRENT.md` и `open_questions.md`.
При расхождении проверить код и активный `data/game_config.tres`, затем исправить этот свод.
Старые главы концепции сохраняют причины и варианты, а не актуальность всех чисел.

## Матч и поле

- Игрок + четыре бота; каждый сам за себя, дуэли, при нечётном числе — призрак-копия.
- До выбора героя общий драфт 4 различных богов из 7, из RNG матча.
  Лавка, заговоры и подарки содержат только этих богов; нейтральные чары доступны всем.
- Выбор одного из трёх героев, 11 героев в активном каталоге. HP обычно 40,
  Илья 50, Кощей 34. Навык не чаще одного раза за раунд, цена растёт.
  Шесть героев имеют аффинити и стартовую постройку в подарок; герой с отсутствующим
  богом не предлагается. Пул богов и подарок видны до выбора.
- Осада каждые пять раундов: двое слабых атакуют лидера; урон армий лидеру 50%.
- Поле 9×10; активная длина пути по уровням магазина: 10/13/22/34 клеток.
  Места под башни открываются вместе с путём. Будущий путь зарезервирован.
  **Автоматического открытия по раундам нет.**
- Башни — фигуры; две одинаковые одного уровня сливаются в следующую, максимум 3.
  Форма не меняется, множитель урона 1/2/4. Достижение уровня 3 даёт выбор подарка.
- Запас вне поля: 8/10/12/14 построек; усиления сохраняются в резерве и при слиянии.
  Подарок может сразу слиться с копией 1-го уровня, без промежуточной установки.

## Силы, усиления и контент

| Бог | Три активные постройки | Роль |
|---|---|---|
| Сварог | Жаровня, Горнило, Огненный венец | Поджог / финишер / область |
| Перун | Искровик, Грозовой столб, Грозовая решётка | Заряд / тяжёлый разряд / три цели |
| Вода | Росник, Желоб, Дождевой круг | Одна цель / группа / вся зона, без урона |
| Стрибог | Ветродуй, Свистящий столб, Ветряной круг | Длинный / узкий / широкий поток |
| Лёд (имя позже) | Иней, Ледник, Ледяное копьё | Холод / область / тяжёлый финишер |
| Чернобог | Чёрная метка, Моровой колокол, Чёрный обелиск | Проклятие / группа / сильный взрыв |
| Бог войны (имя позже) | Самострел, Осадный станок, Ракетница | Прямой урон / две цели / взрыв |

21 постройка, тиры 1–3; числа — в активных `.tres`. У Воды и Ветра только поддержка:
их зона готовит финишер другого бога. Пять атакующих богов работают и без реакции.
На мобе максимум два статуса, третий не вытесняет действующие. Холод и заморозка —
один слот; ветер — геометрия, стан — контроль, слот стихии не занимает.

| На цели → входящий удар | Реакция |
|---|---|
| Мокрота → Молния | Цепь: +60 п.п. к шансу и ×1.1 урона |
| Мокрота → Огонь | Пар ×1.25, замедление30%/1с; снимает мокроту/горение, не поджигает заново |
| Мокрота → Лёд | Заморозка 1.5 с; мокрота поглощается |
| Мокрота → Проклятие | Зараза; мокрота поглощается, взрыв перескакивает на мокрого |
| Мокрота → Ветер | Разгон вперёд на 0.25 клетки и разнос мокроты |
| Горение → Молния | Прожарка ×1.25, стан 0.2 с; горение поглощается |
| Горение → Лёд | Таяние ×1.5; снимает горение и холод |
| Горение → Ветер | Горение +25% и разнос по области |
| Холод/Заморозка → Ветер | Стужа: разнос холода, замедление минимум 25% |
| Проклятие → Лёд | Консервация: один раз +1 с задержки, сила взрыва ×1.5 |
| Заморозка → Физика | Раскол ×1.5, стан 0.4 с; заморозка поглощается |
| Два статуса → Физика | Добивание ×1.4 + накопленный урон проклятия/огня; поглощает метки |
| Заряд → Лёд | Без реакции, статусы сосуществуют |

Одна реакция на удар, приоритет — порядок `config.reactions`: Пар/Прожарка,
Таяние/Заморозка, Раскол/Добивание и остальные. Справка читает эти же ресурсы.
Проклятие: повторный удар берёт максимум силы, не отодвигает взрыв; Зараза выбирает
ближайшего мокрого до 1.5 клетки (равенство — меньший id), поглощает его мокроту.
Ветер разносит статус раз в секунду на 1.5 клетки, до 1.5 с длительности;
получатель не запускает каскад в тот же тик. Замороженного/оглушённого Разгон не толкает.

- Цепь наносит 40% запускающего удара каждой дополнительной цели, без рекурсии.
  Это дополнительный урон, не общий урон, поделённый между всеми целями.
  Запуск — бросок RNG боя по основной цели, дополнительные цели не бросают заново.
  Сговор грозы даёт +10 п.п. шанса за покупку (две), максимум 100%.
  Щит поглощает попадание вместе с эффектом; смертельный основной удар может дать цепь.
- Долгая роса продлевает мокроту на 1 секунду за покупку (две). Три основы идолов
  сохранены: из четырёх богов матча можно посвятить три. Базовые эффекты не требуют идола.
- Встречный ветер тормозит, попутный ускоряет, боковой тормозит в половину силы.
  Потоки одного направления не суммируются; выбирается сильнейший.
  Предел замедления 55%. Ветер усиливает тики горения на 25%.
  Ветродуй по уровням: сила 30/35/40%, длина 5/6/7 клеток; Свистящий столб: сила 20/25/30%, длина 4/4.5/5 клеток.
- Три пустых идола вне сетки: первый заговор посвящает силу, следующие улучшают её.
  Один идол каждого божества; копии идолов не покупаются и не сливаются.
- У новых богов есть заговоры урона и дополнительных целей; Лёд продлевает холод.
- Заговоры из общей витрины усиливают идол или отдельную постройку. Есть предел покупок.
- Чары: один слот на башню, со второго магазина; урон +30%, темп +25% или дальность +0,5 клетки.
- Пробуждение: магазин 4, зачарованная башня уровня 3; один выбор — сила или размах.
  Сила +75% к урону; размах улучшает охват. Для ветра — собственная геометрия потока.
- Старые пороги школ и старый каталог построек в активной сборке отключены.
  Все семь богов активны; привязок башен и резистов пока нет.

## Экономика и армия

- Один ресурс: золото. Старт 20, базовый доход 10; убийства оплачиваются отдельно.
- Постройка стоит 6; обновление витрины обычно 2. У героев бывают модификаторы.
- Магазин 1–4: базовые цены повышения 18/36/60, скидка ожидания 1 за раунд,
  обычный минимум 10; отдельный льготный минимум для скидки героя — 3.
- Продажа: все текущие вложения этой подготовки возвращаются полностью,
  более старые — на треть; Домовой имеет исключение.
- Обычная армия из пяти копейщиков, сама идёт к сопернику. На первом раунде армии нет.
- Ранние множители HP армии р1–4: 0/25/35/65%; с пятого 100%.
- Автоматический рост HP армии 14% за раунд со сложным процентом. Покупки и бафы
  добавляют HP, скорость, количество и особых бойцов. «Злость» отключена.
- В активной армии: копейщик, быстрый боец, броня, воевода, лекарь, витязь со щитом,
  скрытный боец. Новые покупки открываются уровнями магазина.
- Постоянная покупка армии даёт доход: 20% базовой цены, минимум 1, плюс доходный баф.
  Награда за прорывы — 3 золота за фактически снятое HP плюс награда
  конкретного моба только при положительном уроне. Урон после смерти золота не даёт.
- Базовая волна: четыре бойца с 22 HP на первом раунде, далее +1 боец/раунд,
  рост HP 12%. Особые базовые волны сейчас отключены.
- Прорывы без поздних множителей; воевода снимает 5 HP, обычный боец 1.
  Общий предел урона поля за раунд: 4/8/12/16/20 HP для р1–4/5–8/9–12/13–16/17+.
  Базовая волна и обе армии осады расходуют один предел. После его исчерпания
  прорывы не снимают HP и не дают наград; убийства по-прежнему оплачиваются.
- Все армии успевают выйти в стартовое окно 10 секунд; большие пачки выходят плотнее.

## Время и управление

- Подготовка без таймера для тестирования: бой только по «Готов» всех живых людей.
  Матчи одних ботов начинают бой автоматически; старые таймеры остались в фикстурах.
- Бой: общий предел 40 реальных секунд при обычной скорости приложения.
  Первые 20 секунд 1×, следующие 10 — 2×, последние 10 — 5× всей симуляции.
  Пауза и пользовательское ×2 отдельно меняют фактическое время просмотра.
- Остаток по пределу отступает без урона и награды; не считать его прорывом.
- В подготовку верхняя строка показывает число входящих бойцов и предел HP;
  наведение — состав и HP. Карточка заговора показывает число подходящих построек,
  повышение магазина объясняет рост пути/резерва и доступ к пробуждению.
- Полноэкранный UI без скролла: лавка/армия слева, поле справа, три идола под ним,
  инвентарь снизу. Наблюдение чужого боя выбирается фишкой игрока.
- Перенос на поле/копию/инвентарь — установка/слияние/хранение; на лавку — продажа.
  ПКМ — поворот, включая активный перенос. Заговор переносится прямо на свою цель.

## Статистика и текущие ограничения

- Логи версии7 сохраняют счётчики настоящих реакций, реальное прошедшее время и `active_gods`; `hp_lost` — реальные потери,
  `raw_breach_damage` — весь потенциальный урон прорывов. Отрицательный остаток HP сохранён только для тай-брейка выбывших.

- Лечение: в секундном окне на цели учитывается сильнейший импульс. Лекари лечат
  себя и соседей, несколько аур дают покрытие, а не суммарные проценты.
- Предел потерь уменьшил внезапные смерти у ботов; длительность полной подготовки
  и просмотра боя выросла. Нужен живой матч: расчёт не учитывает готовность человека.
  Последовательные сравнения — `docs/16_autonomous_iteration.md`.

## Наблюдение за реакциями — 1 ноября

- Холод и заморозка используют общий слот также при обновлении ветром; вторая метка
  не запрещает такое обновление, настоящий третий статус всё ещё не накладывается.
- Отчёт боя/пробы и лог различают число заражений и фактические переносы проклятия.
  Последние хранятся в battle_report.curse_transfers и рисуют фиолетовую связь со стрелкой.
- Песочница показывает прогноз выбранного удара и кандидата переноса сейчас,
  сроки мокроты/проклятия и причины отсутствия эффекта. Это не гарантия будущего боя.
- Проклятие по-прежнему переносится только при взрыве на мокрого соседа. Предлагаемые
  изменения не включены. Опыт и варианты — 24_reaction_audit.md.

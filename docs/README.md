# Навигация по документации

Порядок чтения задаёт `../AGENTS.md`. При работе над игрой начни с
`../memory/CURRENT.md`; этот индекс открывай, когда нужен документ по теме.
Перед написанием, правкой или ревью кода — в `../DEVELOPMENT.md` блок «Всегда» и нужные разделы по «Оглавлению».
Карта реализации и проверок — `../memory/PROJECT_MAP.md`, правила — нужные разделы
`CURRENT_RULES.md`. Историю, решения и вопросы ищи по теме через `rg`.
Не читать все документы подряд и не перечитывать неизменившиеся инструкции в одном контексте.

## Правило обновления

Реализовал правило → обнови `CURRENT_RULES.md`; завершил блок → `memory/CURRENT.md`;
изменил точки расширения → карту; принял решение → журнал причин; открыл риск → вопросы.
Историю не переписывать как будто так было всегда: отмечать, какое позднее решение заменило раннее.
Большие результаты тестов/баланса хранить в отдельном отчёте, здесь оставлять ссылку.

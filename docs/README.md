## Правило обновления

Реализовал правило → обнови `CURRENT_RULES.md`; завершил блок → `memory/CURRENT.md`;
изменил точки расширения → карту; принял решение → журнал причин; открыл риск → вопросы.
Историю не переписывать как будто так было всегда: отмечать, какое позднее решение заменило раннее.
Большие результаты тестов/баланса хранить в отдельном отчёте, здесь оставлять ссылку.

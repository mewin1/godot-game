# 05 — Мобы (ночная сессия героев, 2026-10-30 — проверить с автором)

Мобы приходят двумя путями: **базовая волна** (одинаковая для всех, растёт по раундам) и
**армии** соперников. Особые мобы появляются в базовой волне с определённого раунда и
покупаются в армию во вкладке «Армия».

## Старые
| Моб | Образ | Особенность |
|---|---|---|
| Обычный | кикимора | — |
| Юнит армии | дружинник со щитом | крепче обычного |
| Быстрый | серый волк | быстрый, хлипкий |
| Бронированный | вепрь в железе | броня 4 (вычитается из каждого попадания) |
| Мини-босс | Лихо одноглазое | много HP, прорыв −5 |

## Как купить конкретного моба
- Вкладка «Армия»: улучшения «Колобок», «Нетопырь», «Знахарка», «Витязь», «Невидимка» — каждое
  навсегда добавляет 1 такого моба в армию (дорожает после покупки, +доход как все улучшения).
- Герой Соловей-Разбойник — навык «Ватага»: 3 разбойника на одну волну.
- Скоморох — колесо «Ярмарка» иногда дарит юнит армии.

## Контры (кто против кого)
- Колобок → Панелька, огонь, баня (много целей / площадь).
- Нетопырь → всё, кроме капкана и заставы.
- Знахарка → убить первой: застава, самострелы (урон по одной цели).
- Витязь → частые выстрелы (самострел, панелька) снимают щит дешёвым попаданием.
- Невидимка → башни у самой дороги (застава, баня, кот учёный рядом).
- Гонец → лёд и кот учёный у конца пути.

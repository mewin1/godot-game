# Опорные изображения подготовки

Автор приложил первые два файла 1 ноября 2026.

- `concept.png` — художественный ориентир автора. Копировать композицию, пропорции,
  согласованность света и среды. Игровые числа, контент и путь брать из проекта.
- `rejected_screen.png` — отвергнутый автором текущий кадр до этой сессии.
- `../../../output/preparation/before_first_round.png` — исходный реальный кадр Godot
  этой сессии. Две покупки за стартовое золото и обычное обновление.
- `../../../output/preparation/latest_first_round.png` — последний реальный кадр
  незавершённой итерации. Три предложения, две башни первого раунда.
- `../../../output/preparation/crowded_before_ground_pass.png` — нагрузочный кадр.
  Семь предложений Василисы, полный резерв, подарок, оба выбора, выбранная башня.
  Снят ДО последней правки дороги, теней и основания пушки. Требует повторного снимка.

Все игровые кадры получены из viewport Godot на pc с NVIDIA RTX 5070.
Обычный первый раунд воспроизводит покупки командами. Это проверочная расстановка,
не запись живой партии автора. В нагрузочном кадре дополнительно выдаются золото и выборы.

Последнее уточнение автора о стиле — «слишком много деталей, текстуры 90-х».
Нужны спокойные материалы, крупные формы и чистые силуэты. Текущая итерация автором
не оценена и не утверждена. Её ограничения и продолжение — `../../prompts/continue_preparation_visuals.md`.

# «Обряд»: существующий интерфейс PvP, 6 ноября 2026

- Автор потребовал полноценную подачу по референсу, затем явно уточнил:
  «не изобретай интерфейс заново, просто скопируй то, что уже есть».
- Самостоятельная отрисовка карточек удалена. Используются настоящие ShopPanel,
  MarketOffer, MatchHud, IdolSlot через адаптеры данных Ritual*. Общие классы
  PvP не менялись. Не возвращаться к отдельной отрисовке UI по макету.
- Полноэкранная арена, более крупный кадр. Локально исправлен масштаб билбордов,
  размещены чаши огня, смягчены свет/швы. Существующие модели и рисунки сохранены.
- DragPayload адаптирован к покупкам, переносам, сбросу на лавку и идол.
- Графические GUI-клики проходят через штатные панели. Callbacks drag-and-drop
  проверены отдельно: push_input не двигает физическую мышь. Ручной плейтест
  системной мышью остаётся непроверенным из-за недоступного CUA-ввода Wayland.
- Детали, команды и логи — docs/31_ritual_trial_run.md. sim и баланс не менялись.
- До этой работы копии четырёх собственных файлов — .godot/ritual_ui_before/.

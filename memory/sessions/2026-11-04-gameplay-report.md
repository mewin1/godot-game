# Отчёт Codex — геймплей, 4 ноября 2026

Работа ограничена отдельной «Дуэлью волхвов» из главного меню.
Обычный матч не переведён на новые правила. Коммитов нет.

## Реализовано

- Шесть планов атаки: разведчики, латники, два порядка смешанного отряда,
  два разделения 3+3 между ранним авангардом и удержанным подкреплением.
  Число/сила бойцов не растёт от разделения; боевых приказов по-прежнему два.
- Яга переносит выбранную башню на подготовленное место с учётом всей формы.
- Домовой меняет две выбранные башни за 2 с без стрельбы обеих; свойства и
  порядок стрельбы сохраняются. Невозможное размещение отклоняется.
- Боты Яга/Домовой реагируют на объявленный налёт через 0,5 с. Прицел и будущие
  команды не читают. Домовой может быть соперником; бессмысленный обмен не делает.
- Две расстановки бота по сиду: средний рубеж и разнесённая оборона.
  Состав/уровни башен одинаковые; своя стартовая расстановка не меняется.
- Таймеры приёмов, отметка автовыпуска, прорывы отдельно по двум группам.
  Повтор сохраняет подготовку и показывает разницу HP с прошлой попыткой.
- Локальные JSON-записи в .godot/duels; replay восстанавливает команды и бота,
  сверяет итоговый хэш. 64-битный сид сохраняется без округления.
- Исправлен воспроизведённый smoke скачок широкой башни при переносе:
  общий ArenaStage3D считает центр/высоту всей фигуры. Модели Claude не менялись.

## Проверки и ограничения

- Точечные: 40 тестов дуэли проходят; smoke трёх героев/разрешений, кликов,
  повторов, сравнения, переноса и JSON-replay проходит. Проверен и CLI replay.
- Итоговый полный check_project запущен; результат будет внесён ниже.
- Реальный кадр не проверен: Vulkan не инициализируется, OpenGL падал в движке.
  Ощущения и баланс не подтверждены автором; контрольные бои доказывают только
  влияние решений. Тестовые записи smoke не считать живыми матчами автора.
- После изменения кода/данных старые replay могут не совпасть — формат не обещает
  совместимость версий. Записи и служебные логи не добавлены в Git.
- Чужие изменения сохранены. Нерешённых пересечений с Claude не обнаружено.

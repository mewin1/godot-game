1. Открыть HTML, в игре пройти Стенд → матч → Проба → выбор башни → Готов.
2. Повторить120матчей на финальном конфиге, чтобы не смешивать версии:
   `godot --headless --path . -s res://tools/balance_sim.gd -- --matches=120 --players=5 --threads=4 --seed=1401`.
3. Анализ `python3 -I tools/analyze_logs.py logs/bots/<папка>`; оценить драфты/реакции,
   поздние чистые серии и развитие. Прежде больших изменений — живой матч автора.
4. Не вводились новые игровые юниты, резисты, привязки. Финальный визуал отложен.

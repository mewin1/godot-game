# Текущее состояние — 1 ноября 2026

Автор отверг перегруженную песочницу. Переделана по его прямому запросу:
семь вкладок богов, три карточки в каждой, перетаскивание из каталога/по полю,
ПКМ и вращение в переносе. Только +1/−1 моб и Запуск/Стоп, без настроек чисел.
Изначально три неподвижные мишени. Новый запуск восстанавливает цели/расстановку/RNG.
Карточки можно возвращать в каталог для удаления. Инструкция — docs/23_combat_sandbox.md.
Текущая переделка пока в рабочем дереве. Приоритет — живая проверка простого экрана автором.
Прежние предложения реакций ниже остаются предложениями; не возвращать сложную панель.

## Существенный вывод

Три секунды мокроты и три секунды проклятия дают узкое окно переноса без обновления:
в контрольном опыте даже1тик опережения воды убирал перенос. Ранняя смерть носителя
его отменяет. «Зараза» в счётчике не означает состоявшийся перенос.
Простой приоритет свежих целей отвергнут как готовое улучшение: при большем уроне
и числе переносов один контроль потерял убийства3→0. Активное прицеливание сохранено.

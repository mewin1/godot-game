# 3D-модель по концепту («нуар»)

Требование автора: модель **соответствует** концепту, а не «похожа» — «абсолютно так же, но в 3D».
Ровные цвета из примитивов автор называет «пластилином». Вес и текстуры не экономить.
Метод: силуэт модели подгоняется к силуэту концепта, затем рисунок концепта проецируется на модель.
Код конвейера — `tools/blender/noir/` (устройство — в шапках файлов), решения — decisions.md, «3D-редизайн».

## 0. Правила
- Blender — фоновый: `~/.local/share/Steam/steamapps/common/Blender/blender -b --factory-startup`.
  Открытый у автора Blender не трогать (несохранённая сцена).
- **Blender-процессы — строго по одному**: параллельные падают в драйвере NVIDIA (EGL) из-за видеопамяти,
  особенно когда запущен ComfyUI. Пачку моделей — циклом, по процессу на модель.
- Запекание — CPU (Cycles GPU в одном процессе с EEVEE: «CUDA context already acquired»). Секунды на модель.

## 1. Концепт (если его нет)
- ComfyUI на :8188 (автор запускает сам). Генератор: `python3 -I tools/concepts/redesign_gen.py gen <группа> <id> --seed N`,
  описания — списки HEROES/UNITS/BUILDINGS/IDOLS в нём же. Результат: `new_concept/<группа>/<id>_<seed>.png` (768×1024).
- Ракурс как у остальных: постройки — ¾ сверху, плита ромбом; персонажи — ¾ спереди в полный рост, тёмный фон.
- Один вид на кадр (в одном кадре «front/side/back» модель рисует трижды фронт). Вид сбоку/сзади Z-Image
  делает плохо — не рассчитывать; обратная сторона модели закрывается фактурой.
- Уроки промптов — память comfyui-concepts (без «lantern», у существ своя рамка, «object on a tile, no pedestal»).

## 2. Модель кодом
- Постройки — `buildings.py`, идолы — `idols.py`, люди и герои — `units.py`. Функция строит детали
  (`kit.box/cyl/sphere/prism/tube/loft/gable`), в конце `join_all("<id>")`; запись в `MODELS`:
  `dict(build=fn, kind="towers"|"units"|..., concept="buildings/<id>_16.png", view=BUILD_VIEW|UNIT_VIEW)`.
- Постройка стоит на `plate(уровень, школа)` — ровно клетка 2×2 м, толщина 0,45 м (по концептам).
  Плита сливается отдельно в `<id>_plate` (своя плита постройки → под центральную клетку фигуры).
- Материалы — только из библиотеки `kit.M(...)` (дерево, камень, металл, ткань, `glow_<школа>`, `window`, `ember`…):
  тип материала по имени выбирает фактуру. Всё, что на концепте светится (пламя, разряды, окна, руны),
  делать светящимся материалом — оно попадёт в маску свечения.
- Люди: общий скелет `skeleton()`, детали привязаны к костям `P(деталь, "кость")`; позу (руки, предметы)
  ставить **как на концепте**, суставы можно переопределить в `j[...]` и передать в `rig(..., joints=j)`.
- Масштаб: 1 м = 1 единица, фронт модели — к −Y (в Godot к камере). Человек ~1,7–1,8 м, герой 2 м.

## 3. Сборка, силуэт, проекция
`tools/blender/noir/build.sh <id> [--no-export]` — делает всё:
1. запекает рисованную фактуру (`paint.py`, текстуры-фактуры `source_art/noir/textures/`, генератор
   `tools/concepts/texture_gen.py`) и маску свечения;
2. ставит ортокамеру ракурса концепта, подгоняет масштаб/сдвиг по рамке силуэта, печатает `силуэт IoU`
   и пишет карту `new_concept/compare/renders/<id>_sil.png`: серое — совпало, **красное — есть только на концепте**,
   **зелёное — только у модели**;
3. проецирует концепт на видимые грани и запекает итоговую текстуру (`project.py`);
4. рендерит `renders/<id>.png`, собирает `new_concept/compare/<id>.jpg` и экспортирует GLB в `assets/noir/<kind>/`.

## 4. Цикл доводки (главное)
Повторять, пока **IoU ≥ 0,8** и рендер рядом с концептом не выглядит как концепт:
- одна сводная картинка «концепт | силуэт | рендер» (PIL, ~240×320 на модель) — экономит контекст;
- по красному/зелёному править размеры и положение деталей в коде (не камеру!);
- типичные причины: деталь толще/тоньше; модель выше концепта относительно плиты (плита «уезжает»);
  предметы в руках не на месте; пламя/дым на концепте крупнее — сделать геометрию крупнее;
- если модель «рассыпалась» — `matrix_world` читался до `view_layer.update()`.

## 5. В игру
- `NoirModels` (`src/view/noir_models.gd`) сам подхватывает `assets/noir/towers/<id>.glb` (+ `<id>_plate.glb`),
  `units/<id>.glb`, `base/terem.glb`; нет файла — прежняя процедурная модель. Id = id ресурса в `data/`.
- `XDG_CONFIG_HOME=$PWD/.godot/local-config XDG_DATA_HOME=$PWD/.godot/local-data godot --headless --path . --import`,
  затем кадр (скилл godot-look) и GUT (скилл godot-check).

## 6. Коммит
Только свои файлы: `tools/blender/noir`, `assets/noir`, `source_art/noir`, `new_concept/compare/*.jpg`,
`new_concept/REPORT_3D.md`. Концепты `new_concept/` целиком в Git не добавлять. Коммит на русском, без соавторства ИИ.
Чужие незакоммиченные правки не трогать (параллельно работает Codex); в decisions.md — только свой кусок.
